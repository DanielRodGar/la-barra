# La Barra

Formulario de conteo de inventario de la cervecería.

- **Formulario:** `index.html` (publicado con GitHub Pages).
- **Envío:** el conteo se manda al webhook de n8n `conteo-barra`, que lo guarda y avisa por Telegram.
- **Modo prueba:** añade `#prueba` al final del enlace para ver el botón "Borrar".
